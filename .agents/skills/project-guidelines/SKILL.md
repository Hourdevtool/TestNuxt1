# Project Guidelines

Follow these 4 rules strictly without exception:

1. **No Code Edits Without Permission**: Never create, modify, or delete project code files unless the user explicitly requests or approves it. Provide explanations, diffs, or code samples only in chat.
2. **Read Next.js Docs First**: Always check official documentation at https://nextjs.org/docs (and local `node_modules/next/dist/docs/`) before planning or coding.
3. **Verify Docs When Uncertain**: If unsure about any Next.js API, feature, or version behavior, verify against https://nextjs.org/docs before responding. Never guess.
4. **Strict TypeScript**: Enforce explicit, strict type definitions for all variables, parameters, and returns. Avoid `any`; use specific types, generics, or `unknown` with type guards.
